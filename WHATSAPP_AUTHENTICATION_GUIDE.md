# WhatsApp Authentication Guide for Mass Messaging

## Why Don't I See Contacts in Mass Messaging?

The contact list in mass messaging appears empty because your WhatsApp accounts require QR code authentication to access real contact data. This is a security measure to ensure only authorized users can access WhatsApp conversations and contacts.

## Step-by-Step Authentication Process

### 1. Access the Mass Sender Page
- Navigate to the Mass Messaging section
- You'll see a "WhatsApp Authentication Status" component at the top

### 2. Check Account Status
- Look for accounts marked as "Sin autenticar" (Unauthenticated)
- Accounts will show a red status indicator when not authenticated

### 3. Generate QR Code
- Click the "Generar QR" (Generate QR) button next to an unauthenticated account
- A QR code will appear below the account list

### 4. Scan QR Code with WhatsApp
1. Open WhatsApp on your mobile phone
2. Go to Settings → Linked Devices (Dispositivos vinculados)
3. Tap "Link a device" (Vincular un dispositivo)
4. Scan the QR code displayed on your screen
5. Wait for authentication to complete

### 5. Verify Authentication
- The account status should change to "Conectado" (Connected)
- The status indicator will turn green
- Contacts will automatically populate in the mass messaging interface

## What Happens After Authentication?

Once authenticated:
- Real WhatsApp contacts will appear in the contact selection list
- You can select individual contacts or use tag filters
- Mass messaging campaigns will be able to send to real WhatsApp numbers
- The system will maintain the connection for ongoing use

## Troubleshooting

### QR Code Not Working?
- Click "Actualizar QR" (Refresh QR) to generate a new code
- Ensure your phone has a stable internet connection
- Make sure you're using the latest version of WhatsApp

### Still No Contacts After Authentication?
- Click the refresh button (↻) next to "Contactos de WhatsApp"
- Check that the selected WhatsApp account is authenticated
- Verify the account has actual conversations/contacts

### Multiple Accounts
- Each account (e.g., "prueba", "Ventas") needs separate authentication
- You can authenticate multiple accounts for different campaigns
- Select the appropriate authenticated account for each campaign

## Security Notes

- QR codes expire after a few minutes for security
- Only scan QR codes from trusted sources
- Authentication sessions are maintained until manually disconnected
- Each account maintains its own authentication state

## Next Steps

After successful authentication:
1. Contacts will appear in the "Contactos de WhatsApp" section
2. Use filters and tags to organize recipients
3. Create and send mass messaging campaigns
4. Monitor campaign progress in the active campaigns tab

For technical support, ensure all accounts show "Conectado" status before attempting mass messaging campaigns.
